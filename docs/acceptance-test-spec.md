# Shipyard 受入検証書(画面操作ベース)

**対象**: Shipyard 全機能(公開前 受入テスト)
**検証方法**: 画面操作のみ(API/DB 直接操作・スクリプト・コード検査は本書に含めない)
**環境**: ローカル(`localhost:3000`)/ 実行者: ___ / 実施日: ______
**ブラウザ**: Chrome / Safari / Firefox いずれか(横断項目で複数)

## 凡例

- **分類**: ◎正常系 / △異常系 / ◇エッジケース
- **結果**: OK / NG / 保留(未実施は空欄)
- 「⚠外部」= Stripe / メール送信 / Twitter 等、外部サービスへ画面遷移する項目。アプリ側の遷移までを確認範囲とする。

## 前提・制約(実行前に必ず確認)

- [ ] Docker Postgres 起動済み / スキーマ適用済み / API・Web dev サーバ起動済み
- [ ] **ブラウザに Clerk でログイン済み**(サインインは人手が必要)
- [ ] **⚠外部依存(Stripe 実決済 / SES メール / Twitter 投稿 / AWS)** はローカル検証不可。アプリからの画面遷移までを範囲とし、実結果は staging で別途確認
